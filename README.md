# Tetris Game

A console-based Tetris implementation in C++ with multiple difficulty levels.

## Features

- Three difficulty levels: Easy, Medium, Hard
- Profile system with name, email, and age
- Score tracking
- Colorful console interface
- Pause functionality

## Controls

- ← (Left Arrow): Move piece left
- → (Right Arrow): Move piece right
- ↓ (Down Arrow): Move piece down
- Spacebar: Rotate piece
- ESC: Pause game

## Difficulty Levels

- Hard: Fastest speed, 15 points per line
- Medium: Normal speed, 10 points per line  
- Easy: Slow speed, 5 points per line

## Building

1. Clone the repository
2. Open in Visual Studio or compile with your preferred C++ compiler
3. Build and run

## Requirements

- Windows OS (uses Windows.h)
- C++ compiler supporting C++11 or later
